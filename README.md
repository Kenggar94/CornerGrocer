# Summarize the and What Problem it was solving
The Corner Grocer Project is a C++ program that keeps track of how often grocery  items are purchased. The program reads the information from an input file and allows the user to look up individual items, display the frequency of all items, and see a histogram of the item frequencies. The main problem of the program was solving was helping the Corner Grocer organize its grocery data and make the information easier to understand.
